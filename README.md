# 圣经人物关系图

目标：用和合本做一张全本圣经的人物关系星图（范围：圣经里的人物，包括耶稣；不收神和圣灵）。凡是有关系的人都连线，比如亲属、认识、说过话、一起经历过同一件事；所有人物按时间轴从左到右排开。**主线是耶稣的家谱，出自马太福音和路加福音。**

## 文件夹

| 文件夹 | 放什么 | 能不能改 |
|---|---|---|
| `数据源/` | 下载的原始数据，原样保留 | 不改。坏了就删掉，运行 `脚本/00_下载数据源.sh` 重新下载 |
| `脚本/` | 处理数据的脚本，按编号顺序运行 | 改 |
| `数据/` | 脚本生成的结果（JSON、核对表） | 不手改，改脚本再重新生成 |
| `网页/` | 关系图网页：`index.html` 是页面，`数据.js` 由 05 脚本生成 | 改 `index.html`；`数据.js` 不手改 |

## 数据源

| 名称 | 内容 | 授权 |
|---|---|---|
| 和合本（eBible.org `cmn-cu89s`） | 中文经文，人名有专门标记 | 公版 |
| BibleData（Brady Stephenson） | 约 3000 个人物（同名的人各有编号）、约 4.4 万条"人物出现在哪节经文"的记录、约 5400 条人物关系 | CC BY 4.0（要注明出处） |
| Theographic（viz.bible） | 3068 个人物、501 个事件（带年代和参与者）、地点 | CC BY-SA 4.0 |
| bible_nouns（Netzschleuder） | 同节共现网络：1773 个专有名词、9131 条连线 | 学术公开数据 |

## 脚本

| 脚本 | 作用 | 输出 |
|---|---|---|
| `00_下载数据源.sh` | 下载全部原始数据 | `数据源/` |
| `01_整理耶稣家谱.py` | 从太 1:1-17、路 3:23-38 读出中文名，逐个对到 BibleData 人物编号 | `数据/耶稣家谱.json`、`数据/耶稣家谱核对表.csv` |
| `02_全本人物中文名.py` | 给全部约 3000 个人物找和合本中文名，标出可信度 | `数据/人物.json`、`数据/地点名.json`、`数据/人名核对表.csv` |
| `03_全本关系.py` | 整理亲属、社会、同节共现三类关系线，加上主线，合成网页用的图数据 | `数据/关系.json`、`数据/图数据.json` |
| `04_时间轴.py` | 给每个人定年代和时期，加上"同一事件"关系线（要在 03 之后运行，会更新图数据） | `数据/时间轴.json`、`数据/图数据.json` |
| `05_网页数据.py` | 算出每个人在图上的位置，把人物、关系、事件和用到的经文打包给网页 | `网页/数据.js` |

运行：

```bash
bash 脚本/00_下载数据源.sh
python3 -I 脚本/01_整理耶稣家谱.py
python3 -I 脚本/02_全本人物中文名.py
python3 -I 脚本/03_全本关系.py
python3 -I 脚本/04_时间轴.py
python3 -I 脚本/05_网页数据.py
```

人工维护的对照表放在 `脚本/对照表/`：
- `事件标题.tsv`：501 个事件标题的中文译名（人名按本项目和合本的写法）。
- `同名称呼.tsv`：同名的人在图上怎么区分（如"犹大（加略人）""西门（奋锐党）"），以及经文里没有名字的人的称呼（如"罗得的妻子"）。没写在这里的同名者，03 脚本会自动加"某某之子""首见某卷某章"。
- `补充关系.tsv`：原数据没有的社会关系，人工补充，每条都要写经文出处。目前补了保罗（师生、同工、受审）和耶稣受审、受难前后的人物，共 62 条。人名可以写编号，也可以写中文名（脚本会按经文找到是哪一位）。

### 从经文句式自动提取的互动（03 脚本）

一节经文里出现"甲 + 动作 + 乙"的句子，就记一条社会关系，如"大卫对约拿单说""扫罗要杀大卫""约押打发使者去见大卫"。动作包括：对话、会面、杀害、膏立、立王、攻击、差遣、祝福、咒诅、责备、下拜、逃避、服侍、拯救、背叛。规则写在 `03` 脚本的 `ACTIONS` 里。

- 全本提取出约 270 处。抽查约九成正确，错的例如"大卫因耶和华击杀乌撒"被当成"大卫杀了乌撒"。每条都附经文，网页里点开就能核对。
- 数量不多的原因：经文里的对话大多写成"对他说""对王说"，用代词而不是人名，程序没法可靠地判断"他"是谁。重要的关系靠 `补充关系.tsv` 人工补。
- "以色列"一律不当作人；"雅各、犹大、利未"等只在创世记里当作人，其余书卷里多半指支派或国家。

## 时间轴（已整理）

- **2993 人都有大概年代**，并分进 12 个时期：太初、洪水之后、族长、寄居埃及、出埃及与旷野、进迦南与士师、统一王国、南北分裂、被掳与归回、两约之间、耶稣在世、使徒时期。
- 年代采用 Theographic 的经文年份，属于**乌雪年表系**（创世约公元前 4003 年，出埃及约公元前 1491 年）。**只用来排先后，不是考证结论**，网页上要写明"约"。
- 年代依据（每个人都记在"年代说明"里）：
  - 生卒年 71 人：取壮年（洪水前的长寿者取中点）；
  - 出现经文的年代 1690 人：取此人出现过的叙事经文里第 25 百分位的年份，家谱章节不算；
  - 按亲属关系推算 704 人：父母比子女早约 30 年，兄弟、夫妻同代。夹在两个已知年代之间的人会被均匀摊开，所以两条家谱都是从古到今顺序排的；
  - 首次出现书卷的年代 533 人：最粗略，以后可以改进；
  - 人工指定：写在 `04` 脚本的 `YEAR_FIX` 里，目前只有古列一人（以赛亚书提前点名，会把他拉早）。
- **事件 501 个**，每个都有年代、经文和参与者；同一事件的参与者之间连了 701 条"事件"线。事件标题目前还是英文，要翻成中文。

## 全本人物和关系（已整理）

- **人物 2993 个**（不含神，见下方"范围"），都有和合本中文名，并附有别名（如彼得的别名：西门、矶法）、性别、首次出现的经文、出现在哪些书卷。
- **中文名可信度**：高 1977 个，中 915 个，低 101 个。中、低的都列在 `数据/人名核对表.csv` 里，可以抽查修改。
  - 高：这个名字在此人出现的经文里几乎每节都有，或者与所有同英文名的人一致（如所有 Joseph 都是"约瑟"）。
  - 中：只出现一两次，靠"排除同节其他人的名字 + 读音相近"判断，抽查大约九成正确。
  - 低：只能靠猜，或者经文里本来就没有名字（如"罗得的妻子""南方王"）。
- **关系线约 1.2 万条**：
  - 亲属 2614 条（父母、子女、夫妻、兄弟姐妹、祖孙、后裔、姻亲等），每条都写明经文出处；
  - 社会 244 条（来源三种：原数据、人工补充 128 条、从经文句式自动提取，见下）；主仆、师徒、君臣、盟友、杀害者等）；
  - 同节 8909 条（两人在同一节经文里一起出现，记了次数和最多 5 处经文）；
  - 主线 115 条（耶稣家谱，马太一支、路加一支）。
- 连线最多的人：大卫、利未、雅各、便雅悯、亚伦、犹大、耶稣、摩西。73 人没有任何连线。

## 耶稣家谱主线（已整理）

- **马太福音**：从亚伯拉罕往下到耶稣，共 41 人，经过所罗门一支。
- **路加福音**：从耶稣往上到亚当，共 76 人，经过拿单一支（经文末尾"亚当是神的儿子"，神不作为图中人物）。
- 从亚伯拉罕到大卫，两边完全相同；到约瑟又会合。两边共有 15 人。

### 已知要注意的地方

1. **马太家谱有省略**，这是经文本身的特点，不是数据错误。马太把世代压成"三个十四代"，所以：
   - 约兰和乌西雅之间省略了亚哈谢、约阿施、亚玛谢三王；
   - 约西亚和耶哥尼雅之间省略了约雅敬；
   - 撒拉铁和所罗巴伯之间，按代上 3:19 还隔着毗大雅。
   在关系表里，这几对记为"后裔"，不是"父子"。
2. **抄本差异**：BibleData 依据的希腊文本在路 3:33 多了"亚德敏"，和合本没有；路 3:36 的"该南"BibleData 没有收录，项目里临时编号为 `Cainan_路3:36`。一律以和合本为准。
3. 耶稣在 BibleData 里和"神"用同一个编号（`YHVH_1`），项目里给耶稣单独编为 `Jesus`。
4. 马太和路加里的撒拉铁、所罗巴伯，BibleData 当作不同的人（编号不同）。学界对此有争议，暂时照原数据处理。
5. eBible 版和合本有两处瑕疵，已在脚本里修正：太 1:3 的"希斯仑"缺字，路 3:37 的"该南"没有标人名。
6. 和合本没有给"耶稣""神""法老""撒但""魔鬼""耶和华的使者"加人名标记，这些写在 `02` 脚本的 `MANUAL` 对照表里。
7. BibleData 把"天父"（YHVH_2）单列，项目里并入"神"；新约里称呼为耶稣、基督、人子等的，都归"耶稣"。
8. 雅各在经文里更常被称为"以色列"（很多其实是指国家），所以在 `02` 脚本的 `MAIN_NAME` 里指定主名为"雅各"。以后遇到类似情况也加在这里。
9. 约书亚记 12 章列了三十一个王，其中十几个"某地王"的名字是猜的（可信度低），以后要人工改。
10. "同节"关系会把家谱、名单里的人都两两连起来，所以有些线只是"名字列在一起"，并不代表真的认识。网页里要能单独关掉这类线。
11. 神（耶和华）是全书的作者和主角，**不作为图中人物**；BibleData 把圣灵也记在神的编号下，所以一并不收。耶稣保留。和神相连的线也都去掉了。
12. **和合本版本**：`数据源/和合本` 用的 eBible.org 版本（标为"新标点和合本"）把一部分人名、地名改成了现代译法，和通行的和合本不同。例如：古列→塞鲁士、推罗→泰尔、以利沙伯→伊利莎白、尼哥底母→尼哥德慕、该撒→凯撒、米利大→马耳他、埃提阿伯→衣索匹亚。另一份网上常见的"新标点和合本"文件也有同样的改动。信望爱站（bible.fhl.net）的和合本是通行写法。2026-11-21 决定暂时不换，项目里的人名、事件标题都按目前这份的写法。

## 网页（已做好）

**打开方式**：在访达里双击 `网页/index.html`，用浏览器打开就行，不用联网。

- 横向是时间：12 个时期每个一样宽，底部是时期名称；纵向像星图，有关系的人聚在一起。
- 金色粗线是耶稣家谱主线：从亚当到大卫两支共用，之后马太一支在上、路加一支在下，到约瑟会合。点的颜色：金色是家谱上的人，蓝色是男性，粉色是女性。
- 滚轮或双指缩放，拖动平移；双击底部时期名，放大到那个时期。手机上从"太初"开始，左右滑动。
- 点一个人：他的关系线亮起来，右边弹出资料卡，包括别名、年代、首次出现、亲属、社会关系、参与的事件、同节出现的人。资料卡里的人名可以点，点经文出处会显示和合本原文。
- 顶部按钮可以单独开关五类线；"关系：一层 / 两层"切换点亮几层关系；"全图"回到全貌。
- 中文名可信度为中、低的人，资料卡里会提示"可能有误"。

改了脚本或数据以后，依次重新运行 01～05，网页会自动用新的 `数据.js`。
